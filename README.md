# PravonixTech — React + Tailwind Local Project

This is a local React/Vite + Tailwind recreation of the PravonixTech website structure and content.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite (normally `http://localhost:5173`).

## Production build test

```bash
npm run build
npm run preview
```

## Notes
- No Vercel deployment or live configuration is included.
- Contact form is local UI only; connect your own backend/email service later.
- Images currently use remote Unsplash URLs. Replace them with local assets in `public/` if you want the site to work without internet access.
- Navigation uses React Router.
